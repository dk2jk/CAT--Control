# CAT--Control
Anhand von einfachen Python-Scripts wird die Kommunikation mit einem ICOM- und einem YAESU-Gerät
gezeigt.

In der Präsentation wird gezeigt, wie die Frequenzabfrage bei einem IC-705 funktioniert, um 
mit der Frequenz-Information Antennen und Endstufen zu steuern. Die Programme wurden auf einem Linux-Laptop getestet.  In der endgültigen Anwendung wurde ein RaspberryPI verwendet

In einem weiteren Beispiel wird ein "Tune-Button" zum Ansteuern eines externen Tuners an einem
YAESU FT-710  in den Varianten für PC bzw. für einen ESP32-Microcontroller programmiert.  Das Ergebnis ist eine Anreihung von CAT-Befehlen.
